# 🍽️ Restaurant Ordering System - CodSoft Internship

A simple and elegant Restaurant Ordering System built using Java, Spring Boot, and Thymeleaf. This project allows customers to view the menu, add items to cart, and place orders seamlessly.

![Java](https://img.shields.io/badge/Java-17-orange) ![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.x-brightgreen) ![Internship](https://img.shields.io/badge/CodSoft-Internship-blue)

### ✨ Features
- **View Menu:** Display all food items with price and description
- **Add to Cart:** Add multiple items to cart
- **Cart Management:** View cart, update quantity, remove items
- **Place Order:** Checkout and place order with success message
- **Responsive UI:** Clean design using Thymeleaf & CSS

### 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot, Spring MVC
- **Frontend:** Thymeleaf, HTML5, CSS3
- **Build Tool:** Maven
- **IDE:** IntelliJ IDEA
